## 🚀 Key Features

- **Hill-Station Theme & Branding**: Deep Forest Green (`#174D38`), Mountain Teal (`#4D8879`), Cream (`#FAF8F1`), and Light Sage (`#E9F0E9`).
- **Interactive Booking Enquiry System**: Powered by React Hook Form & Zod with dynamic WhatsApp message generation and direct helpline links.
- **Transparent Tariff & Packages**: Hourly packages (4h/40km, 8h/80km, 12h/120km, 250km/day), outstation drops (Coimbatore, Mettupalayam, Mysore, Bangalore, Isha Yoga Centre), and verified sightseeing circuits.
- **Sightseeing Showcase**: Curated itineraries covering Ooty (10 spots), Pykara & Mudumalai (10 spots), and Coonoor (7 spots).
- **Nearby Destinations**: Coonoor, Kotagiri, Gudalur, Pykara, and Avalanche.
- **Vehicle Options**: Sedans (4+1), Multi-Utility SUVs (7+1), and Force Tempo Travellers (14+1 Maxi Cab).
- **Travel Photo Gallery**: Filterable masonry gallery with fullscreen responsive lightbox and zoom capabilities.
- **Mobile Sticky Action Bar**: One-touch Call, WhatsApp, and Book Now actions designed for mobile users.
- **SEO & Structured Data**: Schema.org `TaxiService` JSON-LD, Open Graph meta tags, robots.txt, and XML sitemap.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/nikhilmahato26/mmg-tour-and-travels.git

# Navigate into project directory
cd mmg-tour-and-travels

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
